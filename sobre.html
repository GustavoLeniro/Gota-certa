Sobre o projeto

Como funciona

  1. Na página Registrar consumo, você anota quanto gastou numa atividade (por exemplo, um banho de 40 litros).
  2. O site soma os registros do dia e divide pelo número de moradores da casa.
  3. O resultado é comparado com a referência de 110 litros por pessoa.
  4. Você pode corrigir ou apagar qualquer registro, e o painel de atividades mostra tudo o que foi feito.

Como se sustenta como negócio de impacto

O uso por famílias é gratuito, porque é onde está o impacto. A receita viria de quem ganha dinheiro quando o desperdício diminui:

  • Condomínios e pequenos comércios: assinatura mensal por painel com relatórios por unidade ou por setor (lava-rápido, padaria, escola).
  • Companhias de saneamento e prefeituras: licença para campanhas educativas por bairro, com dados agregados e anônimos.
  • Escalabilidade: o mesmo modelo serve para energia e alimentos, trocando apenas a unidade (kWh, kg).

O custo é baixo porque o protótipo roda no navegador, sem servidor próprio. Num produto real, o banco de dados em nuvem seria o principal custo.

Privacidade e LGPD

O site pede só o necessário: atividade, litros, data e uma observação opcional. Não pede nome, e-mail, endereço nem documentos. Os registros ficam apenas no navegador de quem os criou e podem ser apagados a qualquer momento.

Tecnologias

HTML semântico, CSS (Flexbox, Grid e media queries), JavaScript basico e Bootstrap 5.

Gota Certa — protótipo acadêmico de Tecnologia Cidadã (Desenvolvimento Web I, Fatec).

Use apenas dados fictícios. Nenhuma informação sai do seu navegador.
